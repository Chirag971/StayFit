🏋️ StayFitz – Fitness & Lifestyle App

StayFitz is a modern fitness and lifestyle mobile application built using .NET MAUI. It helps users manage their daily fitness activities, shop for fitness products, and set reminders to stay consistent with their health goals.

📌 Features
🔐 User Authentication
Secure login and logout functionality
User session management
🛍️ Shop Module
Browse fitness products (Supplements, Gear, etc.)
Category-based filtering
Clean and responsive UI
🔍 Search Functionality
Search across the entire application
Fast and efficient results using JSON-based data
⏰ Reminder System
Set reminders for workouts or tasks
Notification alert when time is over
Custom reminder text display
🛒 Cart Functionality
Add products to cart
Manage selected items
🎨 Modern UI/UX
Clean and attractive design
Smooth navigation between pages
Light/Dark theme support
🛠️ Technologies Used
Frontend: .NET MAUI (XAML)
Backend Logic: C#
Architecture: MVVM Pattern
Data Handling: JSON

NugetPackageLibraries/Tools:
CommunityToolkit.MVVM
Plugin.Maui.Audio (for reminder sound)


📂 Project Structure
StayFitz/
│
├── Models/           # Data models (Product, Reminder, etc.)
├── Views/            # UI Pages (ShopPage, CartPage, ReminderPage)
├── ViewModels/       # Business logic using MVVM
├── Services/         # Notification, Data services
├── Resources/        # Images, Styles, Icons
└── App.xaml          # App configuration
